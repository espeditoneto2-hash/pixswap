  PIXSWAP v2 — COMO RODAR (3 PASSOS)
═══════════════════════════════════════════════════

1. Extraia este ZIP em qualquer pasta

2. Abra o terminal DENTRO da pasta:
   - Abra a pasta no Explorer
   - Clique na barra de endereço
   - Digite: cmd
   - Pressione Enter

3. Digite os comandos:

   npm install
   node server.js

4. Abra no navegador:
   http://localhost:3000

Preencha o arquivo .env com:

1. OPENPIX_APP_ID
   → Crie conta grátis em openpix.com.br
   → Aplicações > Nova Aplicação

2. BINANCE_API_KEY e BINANCE_API_SECRET
   → binance.com > Perfil > API Management
   → Permissões: Leitura + Spot Trading

3. Hot Wallets (TRON_PRIVATE_KEY etc)
   → Carteiras dedicadas para envio de USDT
   → NUNCA use sua carteira principal!
